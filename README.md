# Minty - De la première carte au Full Set !
Application web de gestion de collection de carte à jouer et à collectionner (TCG). Permet de gérer sa collection de carte (Yu-Gi-Oh, Star Wars Unlimited, Pokemon, ...) en ajoutant les cartes qu'on possède et de visualiser le pourcentages de complétion du Full Set d'une extension.
